# Notion 견적서 뷰어 MVP PRD

## 🎯 핵심 정보

**목적**: 운영자가 Notion에 입력한 견적서를 클라이언트가 로그인 없이 웹에서 확인하고 PDF로 내려받게 한다.
**사용자**: Notion으로 견적을 관리하는 1인 개발자/소규모 프리랜서(운영자)와 견적서를 전달받는 클라이언트.

## 🔐 핵심 결정사항

| 항목           | 결정                                                                                                            | 근거                                             |
| -------------- | --------------------------------------------------------------------------------------------------------------- | ------------------------------------------------ |
| 데이터 원본    | Notion 데이터베이스 (CMS 역할), 관리자 화면 없음                                                                | 운영자가 이미 쓰는 도구를 그대로 사용            |
| 접근 제어      | 로그인 없음 + 추측 불가능한 토큰 URL (Notion 속성 `공유토큰`에 32자 이상 랜덤값)                                | 클라이언트 진입 장벽 제거, 인증 시스템 불필요    |
| 토큰 검증      | 서버에서 Notion 조회 시 `공유토큰` 일치 + `공개 상태`인 건만 반환, 불일치/미공개/만료는 동일한 "접근 불가" 응답 | 존재 여부 노출 방지                              |
| Notion API 키  | 서버 환경변수(`.env`, 커밋 금지)로만 사용, 클라이언트 번들에 노출 금지                                          | 요구사항                                         |
| 검색 엔진 노출 | 견적서 페이지는 noindex 처리                                                                                    | 견적 정보 비공개 유지                            |
| PDF 방식       | 서버 측 PDF 생성 (`@react-pdf/renderer` + 한글 폰트 파일 번들)                                                  | 아래 비교표 참고                                 |
| 캐싱           | Cache Components 모델: Notion 조회를 캐시 + 태그 기반 재검증(수 분 단위 만료), 토큰 검증은 캐시 키에 토큰 포함  | Notion API 속도/제한 대응, 수정 반영 지연 최소화 |

### PDF 생성 방식 비교

| 방식                                       | 장점                                                                          | 단점                                                                              | 판단                                  |
| ------------------------------------------ | ----------------------------------------------------------------------------- | --------------------------------------------------------------------------------- | ------------------------------------- |
| 브라우저 인쇄 (print CSS)                  | 구현 가장 단순, 의존성 0                                                      | 사용자가 "PDF로 저장"을 직접 선택해야 함, 결과물이 브라우저마다 다름              | 보조 수단 (인쇄 레이아웃은 별도 제공) |
| 서버 헤드리스 브라우저 (Puppeteer 등)      | 웹 화면과 동일한 결과물                                                       | Chromium 바이너리 필요, 용량/메모리 큼, 보안망·서버리스 배포에서 문제 가능성 높음 | 제외                                  |
| **서버 React PDF (`@react-pdf/renderer`)** | 순수 Node 동작, 외부 서비스·바이너리 없음, 보안망 친화적, 클릭 한 번 다운로드 | PDF 전용 레이아웃을 별도 작성해야 함, 한글 폰트 파일 직접 포함 필요               | **권장**                              |
| 외부 PDF SaaS                              | 품질 좋음                                                                     | 견적 데이터가 외부로 전송됨, 비용, 보안망 불가                                    | 제외                                  |

## 🚶 사용자 여정

```
1. [운영자] Notion 견적서 DB에 견적서 작성
   ↓ 상태를 "발송"으로 변경, 공유토큰 입력
   ↓ 토큰이 포함된 견적서 URL을 클라이언트에게 전달 (메일/메신저)

2. [클라이언트] 견적서 URL 접속
   ↓ 서버에서 토큰 검증 + Notion 데이터 조회

   [유효] → 견적서 보기 페이지
   [토큰 불일치 / 미공개 / 존재하지 않음] → 접근 불가 안내 페이지
   [유효기간 경과] → 견적서 보기 페이지 (만료 배지 표시, PDF는 유지)
   ↓

3. 견적서 보기 페이지
   ↓ "PDF 다운로드" 클릭

4. [완료] PDF 파일 저장 → 다시 보기 / 브라우저 인쇄 선택 가능

* 루트 주소 직접 접속 → 안내 페이지 (견적서 URL로 접속하라는 문구만 표시)
```

| **F001** | 견적서 조회               | Notion 견적서 DB + 항목을 조회해 화면에 렌더링 (기본정보, 항목 표, 합계, 비고) | 서비스의 핵심 가치                           | 견적서 보기 페이지                        |

| **F003** | PDF 다운로드              | 서버에서 견적서를 PDF로 생성해 파일명 `견적서_{견적번호}.pdf`로 다운로드       | 요구사항의 핵심 시나리오                     | 견적서 보기 페이지                        |
| **F004** | 견적서 상태/유효기간 표시 | 유효기간 경과 여부를 계산해 배지로 표시, 미공개 상태는 차단                    | 클라이언트가 견적 유효성을 즉시 판단         | 견적서 보기 페이지, 접근 불가 안내 페이지 |

## 🛠️ 기술 스택 (최신 버전)

### 🎨 프론트엔드 프레임워크

- **Next.js 16.4.6** (App Router, Turbopack, Cache Components, typedRoutes, partialPrefetching) - 서버 컴포넌트에서 Notion 조회
- **TypeScript 5** - 타입 안전성 (Notion 응답은 Zod로 파싱)
- **React 19.1** - UI 라이브러리

### 🎨 스타일링 & UI

- **TailwindCSS v4** - 유틸리티 CSS, 인쇄용 `print:` 변형 활용
- **shadcn/ui (new-york)** + **Radix UI** - Table, Badge, Button, Skeleton, Alert
- **Lucide React** - 아이콘

### 📝 폼 & 검증

- **Zod** - 환경변수/Notion 응답/토큰 형식 검증
- React Hook Form + Server Actions는 스타터에 포함되어 있으나 MVP는 입력 폼이 없어 사용하지 않음

### 🗄️ 데이터 소스 & PDF

- **Notion API** (`@notionhq/client`, 서버 전용) - 견적서/항목 DB 조회
- **@react-pdf/renderer** - 서버 측 PDF 생성, **Noto Sans KR(또는 Pretendard) TTF** 직접 번들

### 🚀 배포 & 호스팅

- **Vercel** 또는 Node 실행 가능한 환경 (PDF 생성은 Node 런타임 사용, Edge 불가)

### 📦 패키지 관리

- **pnpm**
